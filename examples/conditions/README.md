This directory holds some sample custom review completion conditions (see [docs](https://docs.reviewable.io/repositories.html#custom-review-completion-condition)).  You can copy-paste them verbatim, or use them as inspiration for your own workflow's needs. In particular, `allow_self_review.js` restores the legacy behavior where author marks count as normal reviews, while `require_self_review.js` requires both author self-review and a normal review.
